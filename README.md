# BUCT-auto-evaluation (麦可思教学质量管理平台自动教评插件)

专为北京化工大学 (BUCT) 及各类采用麦可思教学质量管理平台 (`https://jpv2-2.mycospxk.com/`) 的高校量身定制的 Chrome / Edge 浏览器自动教评插件（Manifest V3）。

## ✨ 核心特性

1. **🌟 100% 理想化最优选项智能引擎 ([`evaluator.js`](./evaluator.js))**：
   - **正向评价题**（满意度、教学态度、讲课清晰度、启发思维等）：全选 **「非常满意 / 非常符合 / 完全同意 / 非常好」**。
   - **师德师风与教学规范排查题**（是否存在违规调停课、迟到早退、师德失范等）：自动识别反向排查语义，精准选择 **「没有违反规定 / 从不 / 无违规现象 / 以上均无」**，绝不会因机械选第一项而误选违规。
   - **课程内容与资源题**：自动命中 **「课程很丰富 / 案例充实且紧跟学科前沿」**。
   - **进度/难度/作业量适中题**：自动命中 **「非常合理 / 难易适中 / 进度恰当」**。
   - **全题型支持**：覆盖单选题、多选题（正向全选积极项/负面排查排他项）、滑块打分题（满分 100 分）、矩阵单选题、矩阵星级打分题（满星 5 星）、填空题等。

2. **🚫 非必答问题直接不填（严格遵循学生意愿）**：
   - 针对 **「对课程和老师的建议 / 意见或建议」** 等主观反馈问题，若非系统强制必答，**一律直接不填写（留空）**。
   - 对所有其他标记为选答/非必答的客观选择题，同样**直接跳过不填写**，避免产生多余的主观干预。

3. **🧪 第一轮测试模式（安全测试·绝不提交问卷） ([`page-agent.js`](./page-agent.js))**：
   - 点击插件面板上的 **「🧪 第一轮测试（仅填写·不提交）」**，插件将自动进入待评问卷，在页面上将所有必答题的理想答案填好，并用**高亮绿框**醒目标出。
   - **底层拦截问卷提交请求 (`submitAnswer`)**，绝不向平台接口提交数据。
   - 自动弹出 **「📋 第一轮测试答案核对单」**，详列每道题的题干、所有候选项、已选理想答案及决策理由，支持一键复制 Markdown 给用户核对。

4. **🚀 全自动连评模式**：
   - 核对答案确认无误后，点击 **「🚀 自动完成全部教评（自动提交）」**，插件将开启全自动循环流水线：自动作答 -> 自动提交 -> 自动确认弹窗 -> 自动切换下一位教师/下一门课程，直至全部完成。

## 🚀 安装与使用教程

### 1. 安装插件
1. 运行环境支持：**Google Chrome**、**Microsoft Edge** 或其他 Chromium 内核浏览器。
2. 打开浏览器的扩展管理页：
   - **Edge 浏览器**：访问 `edge://extensions/`
   - **Chrome 浏览器**：访问 `chrome://extensions/`
3. 打开页面右上角或左下角的 **「开发人员模式 (Developer mode)」** 开关。
4. 点击 **「加载已解压的扩展程序 (Load unpacked)」**，选择本项目文件夹所在目录。

### 2. 进行第一轮测试（不提交）
1. 登录学校的 [教学质量管理平台](https://jpv2-2.mycospxk.com/wx/ver4.6.2/index.html?v=4.6.2#/my-task/details/status=UnFinished&type=5&typeCode=Middle&id=1&semester=2026-2027-1)。
2. 页面右上角会出现 **「自动理想化教评助手」** 悬浮控制面板。
3. 点击 **「🧪 第一轮测试（仅填写·不提交）」**。
4. 插件会自动进入首门未完成课程，将所有题目按最理想化答案勾选完毕，并在页面中弹出答案核对单供您逐题审查。

### 3. 一键完成全部任务
- 审查答案符合预期后，直接点击弹窗中的 **「✅ 答案符合预期，开始自动完成全部教评」**，即可全自动完成所有课程与老师的教评任务。
